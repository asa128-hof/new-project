# Российские аналоги Git

## 1. Платформа GitFlic
- **Назначение:** Облачный и локальный сервис для хранения кода.
- **Функционал:** Git-репозитории, встроенный GitFlic CI/CD, управление задачами.
- **Преимущества:** Сервера в РФ, интерфейс на русском, нет санкционных рисков.
- **Ограничения:** Меньше готовых внешних интеграций.

## 2. Платформа Сфера.Мастерская (T1)
- **Назначение:** Корпоративная платформа управления разработкой (замена Bitbucket/Jira).
- **Функционал:** Хранение репозиториев, код-ревью, сложные конвейеры CI/CD.
- **Преимущества:** Высокая безопасность, ориентация на крупные корпорации.
- **Ограничения:** Сложность и стоимость для небольших команд.

## 3. Платформа ИТ-Хаб (СберТех)
- **Назначение:** Современная облачная платформа хостинга кода.
- **Функционал:** Публичные/приватные репозитории, CI/CD, документация.
- **Преимущества:** Удобный интерфейс, высокая скорость работы.
- **Ограничения:** Развивающаяся экосистема.
