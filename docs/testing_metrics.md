## 2. Плотность дефектов
* **Назначение метрики:** оценка концентрации выявленных ошибок на тысячу строк исполняемого кода (KLOC) для контроля стабильности базы кода.
* **Формула расчёта:** `Defect Density = N_defects/Size_KLOC`, где `Size_KLOC = 120/1000 = 0.120 KLOC`.
* **Общий показатель:** `3/0.120 = 25.0 дефектов на KLOC`.
* **Структура дефектов по уровню критичности (Severity):**
  * **Критические / блокирующие (Blocker / Critical):** `0` (`0.0/KLOC`) - матем. логика расчёта нулей изначально была реализована без ошибок.
  * **Значительные (Major):** `1` (`8.3 / KLOC`) - `BUG-01` (ошибка импортирования модулей `src/` без настройки `PYTHONPATH` и отсутствие изоляции временных JSON-файлов в тестах). **Устранено.**
  * **Незначительные (Minor):** `2` (`16.7 / KLOC`) - `BUG-02` (стилистические нарушения PEP 8, **устранено**) и `BUG-03` (отсутствие проверки пустого массива `[]` в `process_module.py`, **запланировано в рефакторинг**).
* **Плотность остаточных дефектов после исправлений:** `1 / 0.120 = 8.3 некритичных дефекта на KLOC`.


## 3. Среднее время нахождения дефекта (MTTD)
* **Назначение метрики:** оценка скорости фидбэка при внесении изменений в репозиторий.
* **Формула расчёта:** `MTTD = Σ(t_обнаружения - t_внесения_изменений)/N_дефектов`
* **Сравнительный замер по выявленным дефектам:**
  1. **`BUG-01` (сбой импорта в Linux-окружении):** обнаружен автоматически системой GitHub Actions через **14 сек** после `git push`.
  2. **`BUG-02` (нарушения стиля PEP 8):** обнаружен линтером `flake8` за **0.4 сек** локально и за **8 сек** на этапе `Lint with flake8` в CI-пайплайне.
  3. **`BUG-03` (граничный случай пустого массива):** выявлен при анализе покрытия ветвлений кода за **+-10 мин** ручного ревью.
* **Итоговый показатель автоматизированного обнаружения в CI/CD:** ср. время реакции пайплайна на дефект с момента отправки коммита составляет **+-12 сек** (против 15-20 мин. при ручном прогоне и проверке кода без автоматизации).


## 4. Итоговая оценка качества ПО
Совокупность метрик (покрытие операторов **88%**, отсутствие критических дефектов, автоматический контроль качества за **12 секунд** в CI/CD) подтверждает готовность протестированной версии (`v1.1.0`) к релизу.
