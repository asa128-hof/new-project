# Отчёт о тестировании интеграции модулей

## 1. Тестовые сценарии

### Сценарий 1: Успешный цикл интеграции (Posetive Test)
* **Цель:** Проверить корректность сквозной передачи данных через JSON-файлы при валидных входных данных.
* **Входные данные:** Квадратная матрица размерности $n=3$: `[[1, 0, 3], [0, 5, 0], [7, 8, 0]]`.
* **Ожидаемый результат:** 
  * Создание валидных файлов `matrix.json` и `results.json`.
  * Успешное чтение данных модулем вывода.
  * Значения полей: `aboveMainZerosCount: 2`, `belowMainZerosCount: 1`, `aboveSideZerosCount: 1`, `belowSideZerosCount: 2`.
* **Статус:** Пройдено успешно (Данные верифицированы автоматическим тестом в CI/CD).

### Сценарий 2: Обработка ошибок взаимодействия (Negative Test)
* **Цель:** Проверить поведение системы при нарушении транспортного протокола (отсутствие / повреждение файлов обмена).
* **Условия:** Удаление или намеренное искажение синтаксиса файла `matrix.json` перед вызовом `process_module.py`.
* **Ожидаемый результат:** Модуль обработки перехватывает исключение, выдаёт сообщение `[Ошибка взаимодействия] Файл matrix.json отсутствует или поврежден.` и корректно возвращает управление диспетчеру `main.py` без аварийного падения всей программы.
* **Статус:** Пройдено успешно (Исключения обработаны через `try-except`).

## 2. Результаты автоматизированной проверки взаимодействия
Взаимодействие модулей зафиксировано в интеграционном тесте `tests/test_main.py` и успешно верифицировано в рамках автоматического пайплайна тестирования на сервере GitHub (GitHub Actions). Сборка проекта завершена со статусом **Success**.
