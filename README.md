Название проекта:
Репозиторий к программе "Нули квадратной вещественной матрицы"
Краткое назначение:
Проект создан для выполнения программы, определяющей положение нулевых элементов относительно главной и побочной диагоналей.
Требования к окружению:
- ОС Windows/Linux/ macOS;
- Git ver 2.0 и выше
Инструкция по запуску: 
1. Откройте папку, либо скопируйте репозиторий
2. Для проверки статуса использовать команду 'git status'
Автор: Кондратенко А.С.

Стратегия ветвления
Выбранная стратегия: В проекте используется стратегия GitHub Flow. 
Обоснование: Данная стратегия идеально подходит для небольших команд и учебных проектов, так как она достаточно проста в понимании, не перегружена лишними правилами и позволяет быстро добавлять новые функции в основную ветку после их проверки.
